# Калькулятор вклада

Простой веб-калькулятор для расчёта дохода по банковскому вкладу (с капитализацией и без).

## 🚀 Запуск

Скачайте репозиторий и откройте `index.html` в браузере.

```bash
git clone https://github.com/Waspish/alex_base.git
cd alex_base
```

## 📝 Как пользоваться

1. Введите **сумму** вклада
2. Укажите **срок в днях**
3. Укажите **годовую процентную ставку**
4. Выберите **капитализацию** (Да / Нет)
5. Нажмите **«Рассчитать»** – увидите чистый доход
